# Astro Startup

Minimal Astro project scaffold. The home page is in `src/pages/index.astro`; shared page markup is in `src/layouts/BaseLayout.astro`.

## Get started

Requires Node.js and npm. Install dependencies with `npm install`, then run `npm run dev` to start the local server. Use `npm run check` to type-check `.astro` and TypeScript files, `npm run build` to produce `dist/`, and `npm run preview` to inspect that build.

The project uses Astro's strict TypeScript configuration and `astro check` for diagnostics. No test runner, deployment adapter, or shopping cart has been configured.
